## 이번에 확인한 동작

| 항목 | 실제 확인 |
|---|---|
| 연습 오답 | 접수 즉시 같은 프레임의 찡그림 시트로 전환 |
| 표정 시간 | 420ms 원장 후 첫 다음 렌더에서 정상 표정, 연속 오답은 종료 시각만 갱신 |
| 공급 중 오답 | catStart·방출 시각·큐 ID 유지, 프레임 rect·발 anchor·몸 크기 유지 |
| 앞발 재합성 | 몸과 책 위 앞발에 동일한 찡그림 시트 사용 |
| 즉시 정답·연타 | 오답 반응 도중에도 정상 분류, 30ms 간격 정답 30권, 큐 길이 4 유지 |
| 기존 규칙 | 오답 −0.5초·콤보 초기화·현재 책 유지, 10콤보 보너스 1회 |
| 일시정지 | 표정과 공급 모션 시간이 함께 정지, 재개 후 남은 시간만 재생 |
| 상태 초기화 | 본 게임 재시작·연습 재시작·연습 완료·게임 종료 때 표정 초기화 |
| 입력 제한 | 메뉴·카운트다운·일시정지 중 입력은 표정에 반영하지 않음 |
| 이미지 장애 | WebP 실패는 PNG, 두 이미지 실패나 잘못된 프레임 메타데이터는 정상 고양이로 대체 |
| 반납함 더미 | 가로 4권·세로 3권, 원래 종횡비 유지, 세 색 재사용 |
| 클리핑·캐시 | 원본 내부 x=55~185, y=148~251 밖 불투명 픽셀 0개. 책 이미지 합성 7회 후 같은 캐시 유지 |
| 버튼 | 보이는 글씨는 분류만, 108×64 터치 영역과 눌림 유지, 상자 이름 유지 |
| 접근성·키보드 | 일반/어린이/유아 자료 분류 aria-label, 1·2·3 키 조작 유지 |
| 화면 | 360×640과 430×932 비율·배치 유지, 게임 제목 유지 |

첨부 표정 PNG/WebP를 기존 시트와 디코딩 비교하여 알파 차이 0개와 얼굴 부분 이외의 몸·발 픽셀 유지를 확인했습니다. 상세 숫자는 verification/feedback-assets.json에 있습니다.
