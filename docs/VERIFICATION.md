# 기록 측정 버전 검증

버전: book-sort-2.1.0. 순위표를 제거한 현재 코드로 다시 실행한 결과입니다.

- 게임 규칙 테스트 **5개 통과, 실패 0개**.
- 실제 Chromium 브라우저 시나리오 **9개 통과, JavaScript 오류 0개**.
- 코드와 WebP 초기 에셋 크기: **174,821바이트**.
- 결과 파일: verification/unit-tests.tap, browser-results.json, asset-budget.json.

## 실제 확인

| 항목 | 확인 결과 |
|---|---|
| 순위표 제거 | 시작·결과 화면에 순위표나 별명 입력 없음 |
| 통신 제거 | 정적 코드·에셋 GET만 발생, 기록 API·POST·외부 서비스 요청 없음 |
| 이번 기록 | 정리 권수·실수·최고 콤보 표시 |
| 기기 최고 기록 | 더 높은 기록만 갱신, 낮은 기록으로 덮어쓰지 않음 |
| 기록 유지 | 새로고침 후 최고 기록 복원, 이전 버전 저장 값 사용 |
| 저장 차단 | 메모리 기록과 안내 표시, 게임 종료·다시 하기 정상 |
| 360×640 / 430×932 | 버튼 잘림 없음, 화면 비율 유지 |
| 튜토리얼 | 세 색 3권, 본 게임 기록과 분리 |
| 입력 | 정답당 제거·보충 1회, 오답 큐 보존, click 중복·키 반복 무시 |
| 연타 | 30ms 간격 연속 입력 중 큐·정리 수 정상 |
| 시간과 보너스 | 오답 −0.5초, 첫 10콤보 +3초 1회, 마감 시각 우선 |
| 일시정지 | 긴 중단·탭 숨김 후 기록과 활성 시간 보존, 명시적 재개 |
| 재시작 | 점수·콤보·보너스·비행·고양이·판 ID 초기화 |
| 완료 | 성공 이벤트 또는 콜백 한 번, 결과 닫기로 반복되지 않음 |
| 통신 단절 | 에셋 로드 후 오프라인으로 바꿔도 완료·기록 저장 정상 |
| 이미지 | WebP 정상 사용, 실패 시 PNG 9개 대체 로드 |
| 배포 경로 | /repo/ 하위 경로에서 상대 경로 로드 정상 |

360-start.png, 360-game.png, 360-result.png, 430-game.png가 현재 버전의 화면입니다.

브라우저는 로컬 소스를 Playwright 요청 가로채기로 https://book-sort.test/repo/에 연결하여 실제 렌더링·키보드·포인터 입력을 검사했습니다. 사용자 환경의 루프백 접속 제약 때문에 이 경로를 사용했습니다. 실제 GitHub Pages 배포와 실물 휴대전화 검증은 수행하지 않았습니다.

게임을 처음 열 때에는 파일을 받아야 합니다. 오프라인 검사는 처음 실행 후 통신이 끊긴 경우이며, 최초 오프라인 접속을 위한 서비스 워커는 추가하지 않았습니다.
